DrawInstanced vs ExecuteIndirect

项目 DrawInstanced ExecuteIndirect
Draw Count CPU 指定 GPU 决定
Culling CPU GPU
LOD CPU GPU（或混合）
Instance Buffer CPU 更新 GPU 更新
Draw Call CPU Record GPU Argument Buffer
CPU 开销 高 很低
GPU 开销 中 略高（Compute）
适合 中小场景 大型开放世界
