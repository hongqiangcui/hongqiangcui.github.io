Unreal Engine 商业项目常见扩展点（最终版）

本文整理了商业 UE 项目最常见的扩展入口（Extension Points）与 Override 点，适合作为架构设计与源码阅读索引。

总览

层级 常见 Override / 扩展点 主要用途 商业项目使用频率

事件解耦 Delegate、Multicast Delegate、Dynamic Delegate 模块解耦、事件广播 ★★★★★

Gameplay GameMode、GameState、PlayerController、PlayerState、Pawn、Character、Actor、ActorComponent 游戏主体架构 ★★★★★ Framework

Subsystem EngineSubsystem、GameInstanceSubsystem、WorldSubsystem、LocalPlayerSubsystem、EditorSubsystem 全局管理器 ★★★★★

GAS AbilitySystemComponent、GameplayAbility、GameplayEffect、GameplayCue、AttributeSet 技能、属性、Buff ★★★★★

数据驱动 Interface、GameplayTags、PrimaryDataAsset、DataAsset、DataTable、AssetManager、DeveloperSettings 数据驱动、配置管理 ★★★★☆

Networking Replication、RPC、FastArraySerializer、ReplicationGraph、ReplicateSubobjects 联机同步 ★★★★☆

World Partition Streaming Source、Streaming Policy、Runtime Spatial Hash、Data Layer、HLOD 开放世界流送 ★★★★☆

AI AIController、BehaviorTree、StateTree、EQS、AI Perception AI 系统 ★★★★☆

Input Enhanced Input、Input Mapping Context、Trigger、Modifier 输入系统 ★★★★☆

UI UMG、Slate、Widget UI ★★★☆☆

Blueprint Blueprint、BlueprintImplementableEvent、BlueprintNativeEvent、Function Library 设计师扩展 ★★★★☆

Plugin / Module Runtime Plugin、Editor Plugin、Runtime Module、Editor Module、Developer Module 工程模块化 ★★★★★

Game Feature Game Feature Plugin、GameFeatureData、Experience 热插拔玩法、DLC ★★★★☆

Editor / Tooling EditorSubsystem、Detail Customization、Commandlet、Validation 编辑器工具 ★★★☆☆

一、Gameplay Framework

核心对象：

  • GameMode
  • GameState
  • PlayerController
  • PlayerState
  • Pawn
  • Character
  • Actor
  • ActorComponent

职责：

  • 游戏规则
  • 玩家控制
  • 世界对象
  • Gameplay 生命周期

常见 Override：

  • BeginPlay()
  • Tick()
  • EndPlay()
  • PossessedBy()
  • OnRep_xxx()
  • SetupPlayerInputComponent()

二、Actor / ActorComponent 生命周期

常见 Hook：

  • OnComponentCreated()
  • RegisterComponent()
  • OnRegister()
  • InitializeComponent()
  • PostInitializeComponents()
  • BeginPlay()
  • TickComponent()
  • OnUnregister()

用途：

  • 初始化
  • 注册到 World
  • 创建 Render State
  • 创建 Physics State
  • Tick 更新
  • 注销

三、可见性（Visibility）

常见接口：

  • SetVisibility()
  • SetHiddenInGame()
  • OnVisibilityChanged()

用途：

  • LOD
  • Streaming
  • UI 显隐
  • Gameplay 显示控制

四、Activation

  • Activate()
  • Deactivate()
  • OnComponentActivated()
  • OnComponentDeactivated()

适合：

  • 延迟初始化
  • 功能开关
  • Pool

五、Subsystem

  • EngineSubsystem
  • GameInstanceSubsystem
  • WorldSubsystem
  • LocalPlayerSubsystem
  • EditorSubsystem

适合：

  • Manager
